空间节点分类 涉及实地地名 核心现状本底 与 关键特征描述
核心生态/公共空间 国际慢城桃花扇广场、固城湖水慢城、青山茶场 兼具大规模自然体量与既有大型赛事流量，具备萌宠/动物本底，但公共导向与常态化二消极其薄弱。

公共展陈/消极空间 慢城展馆（游客中心内部） 处于典型的“有资产、无运维”消极休眠状态，未能发挥慢城IP的叙事与流量前置集散功能。

节点剖析 01：核心生态景区与公共开放空间

桃花扇广场、固城湖水慢城及青山茶场的优势禀赋与运营痛点

无门票制

国际慢城桃花扇广场

拥有大面积天然大草坪、花海视觉景观。场地内引入了动物资源（鹿），且具备举办大型户外活动（音乐节）的空间经验。

已实现物理隔离分区

宠物友好与亲子旅游实现了明确的物理分区，有效平抑人宠冲突。

有门票制

固城湖水慢城

相比国际慢城更靠近市区。拥有萌宠乐园（羊、鹿）以及红山动物园分部（湿地动物园），拥有极高密度的草坪、荷花池和季节性花海。

缺乏自主权

湿地动物园作为分部无自主权，且门票机制一定程度上拦截了日常携宠市民的高频消费。

传统观光

青山茶场

知名影视剧《人民的名义》实景取景地。目前属于传统低价旅游团的核心打卡地点之一，主要开展常规采茶活动。

典型“有流量无二消”

路遇南京跟团阿姨坦言：“被拉过来完全不知道好玩在哪”。顶级影视IP长尾效能流失严重。

节点剖析 02：住宿与城镇重资产的“软硬错配”

归来兮度假庄园酒店与慢城小镇的经营现状与空间统筹

重资产硬件特征

归来兮度假庄园酒店

定位高端，拥有40多栋独立独栋别墅资产，配备成熟的内部接驳车系统。

运营现状访谈： “虽然允许宠物准入但无任何配套。目前存在在对外宣传‘宠物友好’方面的顾虑，担心引发普通高端客户与携宠客群的空间不兼容问题，前期设计时未配置动线硬隔离。”

实地调研揭示了高端配套与细分运营服务之间的错配

空间资源现状

慢城小镇 / 慢城展馆

  • ● 大量空置资产： 慢城小镇目前使用的空间极局限（仅银发中心及古琴非遗房），粮仓美术馆等高价值建筑处于闲置状态。
  • ● 战略合作规划： 携程战略合作项目“丽呈宠物酒店”正在建设规划中，构成未来产业链支点。
  • ● 展陈空间状态： 游客中心内部慢城展厅介绍慢城由来及规划，目前处于无运营维护状态。

小镇具备大规模高质量睡眠资产，极具唤醒空间红利潜力
